# gomoku.koplugin

A Gomoku (five-in-a-row) plugin for [KOReader](https://github.com/koreader/koreader).

## Rules

Two players take turns placing stones on a 15×15 board. Black plays first.
The first player to align **5 unbroken stones** — horizontally, vertically, or
diagonally — wins.

## Features

- **15×15 board** — standard competition size
- **1-player mode** — minimax AI at three difficulty levels (easy / medium / hard)
- **2-player mode** — two humans on the same device
- **Undo** — take back one move (or two in 1-player mode to keep it your turn)
- **Stone choice** — in 1-player mode, pick whether you play Black or White
- **Auto-save** — board state saved automatically

## Controls

| Action | How |
|--------|-----|
| Place a stone | Tap a cell |
| Undo last move | Tap **Annuler** |
| New game | Tap **Nouveau** |
| Switch players mode | Tap **1 joueur** / **2 joueurs** |
| Change difficulty | Tap difficulty button |
| Show rules | Tap **Règles** |
